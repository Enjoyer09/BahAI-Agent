## Mobile composer mic/send overlap fix (separate bug report)
- Symptom: on mobile, the Voice Mode mic button overlapped the send button.
- Root cause: `App.tsx` rendered a Voice Mode mic as `absolute right-4 bottom-4`
  inside the composer dock. On mobile the dock is full-width and the Composer's
  send button sits at the right edge, so the floating mic landed on top of it
  (desktop was fine because the composer is centered, leaving right-side space).
- Fix: moved the mic inline into `Composer`'s input row (left of send) as a
  fixed 44px `.composer-voice-button`; removed the absolute floating button;
  `App.tsx` passes `onVoiceMode` to `<Composer>` only when web_chat + speech
  supported. Verified `tsc -b` clean + `vite build` green.
- Files: `frontend/src/components/chat/Composer.tsx`, `frontend/src/index.css`,
  `frontend/src/App.tsx`.

## Mobile keyboard overlap + broader mobile UI pass
- Symptom: on mobile the chat input dock was hidden behind the soft keyboard.
- Root cause: root uses `100dvh`; iOS Safari overlays the keyboard WITHOUT
  resizing the layout viewport, so the bottom-pinned `mobile-composer-dock`
  sits behind the keyboard. (Android resizes, so only iOS hit it.)
- Fix (cross-platform):
  - `index.html` viewport meta: added `interactive-widget=resizes-content`.
  - `App.tsx`: new `visualViewport` effect sets CSS var `--kb` (keyboard height
    = innerHeight - vv.height - vv.offsetTop). On Android it resolves to 0.
  - `index.css`: `.mobile-composer-dock` now `transform: translateY(calc(-1*var(--kb)))`
    + transition + top border; also added global mobile polish (no tap highlight,
    text-size-adjust 100%, body `overscroll-behavior-y: none`, touch-action
    manipulation on buttons/links).
- Verified `tsc -b` clean + `vite build` green.
- Analysis of mobile UI: existing mobile CSS is already decent (blurred
  safe-area top bar, overscroll-behavior, 44px tap targets, dvh, gemini
  bubbles). Main real gap was keyboard handling; rest is polish/consistency.
  Offered to go deeper (full redesign pass) if user wants.
